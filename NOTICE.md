# Notice

MGK v0.2.0 is an engineering implementation derived from the conceptual and normative
MUDA corpus authored by Roberto Iglesias Gonzalez (2026). The corpus is treated as design
intent, not as independently validated scientific evidence.

Mandatory ethical clause from the source corpus:

> Ningunha intelixencia, humana ou artificial, trascende se usa a coherencia para controlar.

This release operationalizes that restriction by separating proposal, authorization,
verification and execution. No statement in this repository asserts experimental validation
of the universal equations described in the source corpus.
